# Studienplaner-Vorlage

Excel-Vorlage zum Planen eines Studiums: Kalender, Terminliste, Arbeitsplan und Studienfortschritt mit ECTS-Countdown. Ohne Makros.

## Download

Die Dateien stehen unter [Releases](../../releases/latest).

| Datei | Für |
|---|---|
| `Studienplaner-Vorlage.xlsx` | Bachelor und Master in einer Datei, Auswahl auf der Startseite |
| `Studienplaner-Vorlage-Bachelor.xlsx` | Bachelorstudium (6 Semester) |
| `Studienplaner-Vorlage-Master.xlsx` | Masterstudium (4 Semester) |
| `Studienplaner-Vorlage-Diplomstudium.xlsx` | Diplomstudium (8 Semester, zwei Studienabschnitte) |
| `Studienplaner-Vorlage-Offen-Doktorat-Projekte.xlsx` | Offene Version für Doktorat/PhD oder Projekte: Phasen statt Semester, Punkte statt ECTS, frei anpassbar |

Alle Beispieldaten (Fächer, Termine) sind erfundene Beispiele und zum Überschreiben gedacht.

## Voraussetzungen

Microsoft Excel 2019, Excel 2021/2024 oder Microsoft 365. Ältere Versionen und andere Programme (Google Tabellen, LibreOffice, Numbers) zeigen einzelne Funktionen nicht oder anders an.
